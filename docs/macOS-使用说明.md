# GamePulse macOS 使用说明

GamePulse（游戏脉冲）是一款常驻 macOS 菜单栏的游戏状态组件，以手机桌面组件风格集中显示五款游戏的体力恢复进度和每日任务状态。

## 系统要求

- macOS 14 Sonoma 或更高版本
- Apple 芯片与 Intel 处理器均支持
- 中国大陆官服账号

## 安装

1. 从 GitHub Releases 下载 `GamePulse-macOS-universal-v1.0.0.zip`。
2. 解压后将 `GamePulse.app` 拖入“应用程序”文件夹。
3. 首次启动时，按住 Control 点击应用，选择“打开”，再确认一次。
4. 启动后点击屏幕右上角菜单栏中的仪表图标。

当前公开版本使用临时本地签名，未经过 Apple 公证，因此不建议直接双击首次启动。请只从本项目的 GitHub Releases 下载。

## 登录游戏账号

点击主面板右上角的齿轮进入设置：

- **原神与崩坏：星穹铁道**：使用同一个米游社账号，点击“开始完整授权”，根据提示连续扫描两次二维码并在手机确认。
- **绝区零**：可登录另一个米游社账号，操作方式相同。
- **明日方舟**：使用森空岛 App 扫描二维码并确认授权。
- **鸣潮**：输入库街区绑定的手机号，获取并填写短信验证码。

完成授权后点击“保存并刷新”。未登录的游戏会显示演示数据；授权失效时卡片会提示重新登录。

## 日常使用

- 点击循环箭头立即刷新全部游戏。
- 在设置中可选择 5、10、15 或 30 分钟自动刷新。
- 点击电源图标完全退出应用。
- 关闭面板不会退出，GamePulse 会继续驻留菜单栏。

## 隐私

- 扫码凭据和登录 Token 只保存在当前 Mac 用户的本地存储中。
- 手机号和短信验证码不会保存。
- 日志不记录 Cookie、Token、手机号或验证码。
- 凭据不会发送给 GPT 或其他云端模型。

诊断日志位于：`/tmp/GamePulse-diagnostics.log`。如果遇到数据异常，请先点击刷新并查看卡片中的具体提示。
